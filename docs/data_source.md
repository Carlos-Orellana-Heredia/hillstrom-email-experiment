# Data source

This project uses the public Hillstrom MineThatData E-Mail Analytics and Data Mining Challenge dataset. It contains 64,000 customers randomly assigned to one of three conditions: Men's email, Women's email, or no email.

The data include pre-assignment purchase-history characteristics and outcomes measured over the next two weeks: website visit, conversion, and spend. The project downloads the source file locally and excludes the raw CSV from version control.

Source: https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html
